# Your notes

This folder is yours. Labs ask you to save notes, plans and samples here, and some lab checks look for them.

- `templates/`: copy a template when a lab tells you to (`cp notes/templates/w1d2-modes.md notes/`)
- `cost-log.csv`: what each lab cost you (`uv run labcheck log <lab> <usd> "note"`)
- `.cost-ledger.json`: written by the status line (git-ignored; estimates only)

Commit your notes. They're part of your course record.
