# Community contributions

Built something you're proud of? Share it here so future cohorts can learn from it.

Good contributions:
- skills, commands, hooks, output styles and subagents that helped you
- MCP servers or tool designs
- capstones (with their README, design doc and review log)
- new quiz or mock-exam questions *with explanations*

How:
1. Create a folder: `community_contributions/<your-github-handle>-<short-name>/`
2. Include a `README.md`: what it is, how to use it, what it costs to run.
3. **No secrets, no API keys, no personal data.**
4. Open a PR to the course repository.

Week folders also have their own `community_contributions/` for lab-specific variations.
